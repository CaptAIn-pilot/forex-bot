# Forex-Bot

This repository contains the details of an advanced Forex trading bot built using the cTrader OpenAPI.  
The bot is designed to automate trading processes, such as placing and managing orders. It supports both demo and live accounts, aiming to improve trading efficiency for users.

## Features
- Seamlessly connects to the cTrader OpenAPI.
- Automates trading processes, including placing buy/sell orders.
- Supports risk management with stop-loss and take-profit functionalities.

## Purpose
This bot is intended for personal use and testing purposes to enhance trading efficiency, reduce manual workload, and support informed decision-making in the Forex market.  
The bot does not process personal user data without explicit consent and fully complies with GDPR regulations, ensuring data protection and privacy.
